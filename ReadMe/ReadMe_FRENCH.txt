 Configurations système
______________________________

Systèmes d'exploitation compatibles :

Grand Theft Auto III requiert DirectX 8.1 de Microsoft.
Les systèmes d'exploitation compatibles sont :

	Windows 98
	Windows 98 Second Edition
	Windows Millennium
	Windows 2000 Professionnel (Station de travail)
	Windows XP (Personnel et professionnel)

Les systèmes d'exploitation suivants ne sont pas compatibles :

	Windows 95
	Windows NT (toutes versions)
	Mac OS
	Linux
	BEOS

Configuration matérielle minimum requise
	
	Processeur 450 MHz Intel Pentium III ou AMD Athlon 
	96 Mo de RAM
	Lecteur de CD-ROM/DVD-ROM 4 vitesses
	700 Mo d'espace disque dur libres
	Carte graphique 16 Mo avec pilotes compatibles DirectX 8.1
	Carte son compatible DirectX 8.1
	Clavier
	Souris

Configuration matérielle recommandée
	Processeur 700(+) MHz Intel Pentium III ou AMD Athlon
	128(+) Mo de RAM
	Lecteur de CD-ROM/DVD-ROM 8 vitesses
	700 Mo d'espace disque dur libres
	Carte graphique 32(+) Mo avec DirectX 8.1
	Carte son compatible DirectX 8.1 avec son surround
	Manette de jeu (port USB ou joystick)
	Clavier
	Souris

 Informations générales
______________________________

DirectX :
Grand Theft Auto III requiert DirectX 8.1 de Microsoft pour fonctionner.
Par conséquent, nous vous recommandons d'installer des pilotes de cartes
graphiques et sonores compatibles avec DirectX 8.1. Vous pouvez également
utiliser une véritable carte matérielle DirectX 8.0 / DirectX 8.1.

Windows XP :
Nous vous recommandons d'utiliser des pilotes distribués par des fabricants
pour Windows XP (par exemple, des pilotes nécessitant un changement des
commandes de l'utilisateur pour le matériel spécifique), au lieu des pilotes
installés par défaut par Microsoft lors de la configuration de la machine.

Mémoire :
Grand Theft Auto III nécessite au minimum 96 Mo de mémoire pour fonctionner.
Pour obtenir des performances optimales, nous vous recommandons de disposer
d'au moins 128 Mo de mémoire (256 Mo si possible).

Applications compatibles :
Grand Theft Auto III a été conçu pour tirer le meilleur parti de la machine
sur laquelle il fonctionne. Par conséquent, nous vous recommandons de fermer
toutes les applications en cours avant de lancer Grand Theft Auto III.

Espace disque libre :
Grand Theft Auto III requiert au minimum 200 Mo d'espace disque libres
lorsqu'il fonctionne pour la mémoire d'échange.

Mémoire graphique :
Grand Theft Auto III nécessite une carte graphique avec 16 Mo de mémoire
graphique ou plus pour fonctionner. Grand Theft Auto III ne se lancera pas
sur une machine dotée de moins de 16 Mo de mémoire graphique.

Processeurs AMD K6/2 et K6/III :
Avec ces processeurs AMD, Grand Theft Auto III tourne trop lentement pour
fonctionner correctement.

 Installation
______________________________

Insérez le disque de Grand Theft Auto III dans le lecteur de CD-ROM / DVD-ROM. 
Si la fonction Autoplay est activée, le programme d'installation se lance
automatiquement. Si la fonction Autoplay est désactivée, utilisez l'Explorateur
pour naviguer sur le disque 1 de Grand Theft Auto III et lancer manuellement
le programme setup.exe

Espace occupé
Grand Theft Auto III requiert environ 700 Mo d'espace disque libre.

Désinstallation
Lorsque Grand Theft Auto III est désinstallé, les répertoires "mp3", 
"skins" et "SaveGames" ne sont pas supprimés. L'utilisateur peut toutefois
les désinstaller manuellement.

 Configuration
______________________________

Fournisseur son :
Le son API sélectionné dans le menu des options de Grand Theft Auto III
peut affecter les performances du jeu. Choisissez d'autres fournisseurs
de son pour obtenir de meilleurs résultats. Essayez par exemple, Software,
MSS Fast, RSX, Direct Sound Hardware ou Direct Sound Software.

Modelage acoustique dynamique :
Désactivez cette option dans le menu des options sonores pour gagner un
peu en performances.

Traînées :
Désactivez les effets de traînées dans Grand Theft Auto III pour améliorer
la vitesse du jeu.

Résolution de l'écran :
Choisissez une résolution d'écran faible pour que Grand Theft Auto III soit
plus rapide sur des machines lentes. N'hésitez pas à opter pour des couleurs
16 bits au lieu de 32 bits si votre machine est lente.

 Problèmes rencontrés
______________________________

Windows XP + cartes graphiques nVIDIA (ou d'autres marques) :
Nous avons découvert qu'avec Windows XP, certains problèmes graphiques se manifestent dans le menu du jeu mais aussi au cours du jeu.
Techniquement, ce problème peut être résolu en utilisant une version plus récente du fichier d3d8.dll que celle fournie sur le CD-ROM de Windows XP. (La version sur le CD-ROM de Windows XP qui entraîne ce problème est 5.1.26000.0. Les versions testées sans erreur sont 5.1.2600.15 et 5.1.2600.29.)
Actuellement, la seule façon que nous connaissons pour mettre à jour ce fichier dll consiste à installer le patch de Windows XP : "The Computer Cannot Enter Standby or Hibernate If a Direct3D-Based Screen Saver Is Running (Q306676)" que vous pouvez télécharger à partir du site Internet suivant : http://download.microsoft.com/download/whistler/Patch/Q306676/WXP/EN-
US/Q306676_WXP_SP1_x86_ENU.exe.
A l'avenir, cette mise à jour pourrait faire partie du pack de services officiel de Windows XP, d'une mise à jour de compatibilité de Windows XP ou d'une mise à jour de DirectX 8.1.

Cartes graphique Power VR Kyro 2 :
Nous n'avons pas pu rendre entièrement compatible cette carte graphique en
raison de la nature du rendu avec cette carte et, par conséquent, certains
effets de textures ne s'affichent pas correctement, même s'il ne s'agit là
que d'un problème mineur. Nous vous recommandons d'utiliser cette carte
graphique avec des couleurs 32 bits, puisqu'en 16 bits, nous avons découvert
un problème rare de tampon de profondeur (depth buffer), qui peut être résolu
en passant en mode 32 bits. Nous vous conseillons également d'effectuer les
paramétrages suivants :
=> Allez dans la fenêtre de dialogue des propriétés avancées d'affichage
	Sélectionnez la section Direct 3D et créez un nouveau profil pour gta3.exe,
	Puis, dans ce profil :-
		DESACTIVEZ W buffer
		ACTIVEZ external depth / stencil buffer format
		ACTIVEZ Direct 3d / stencil buffer format
		ACTIVEZ depth / stencil buffer format
		ACTIVEZ depth / stencil buffer loading

Cartes son Aureal :
Nous avons assisté à de nombreux blocages avec les cartes son Aureal. Ce
fabricant n'existe plus et ne sort donc plus de nouveaux pilotes. Nous avons
eu bon nombre de problèmes avec la compatibilité des cartes Aureal dans le
passé qui ne peuvent être résolus par les pilotes actuellement sur le marché.
Les autres fournisseurs rencontreront donc davantage de succès que le
fournisseur d'origine Aureal (par exemple : Software, MSS Fast, RSX, Direct
Sound Hardware ou Direct Sound Software).

Chipsets sonores intégrés à la carte-mère :
Nous avons découvert que certains chipsets sonores intégrés à la carte mère
n'ont pas de hardware sound buffer et plantent avec Grand Theft Auto III. Si
vous lancez "DXDIAG" de Microsoft et effectuez des tests sonores, un message
d'erreur disant qu'un hardware buffer n'est pas compatible s'affiche et vous
demande si vous souhaitez utiliser un software buffer. 
Sélectionnez un software buffer pour que ce chipset sonore fonctionne avec 
Grand Theft Auto III.

Défragmentation du disque dur :
Si vous rencontrez de brefs ou périodiques ralentissements en conduisant, il
se peut que Grand Theft Auto III ait du mal à récupérer des données de votre
disque dur assez rapidement. Nous vous recommandons donc de lancer régulièrement
votre utilitaire de Défragmentation de système afin d'obtenir une vitesse
optimale pour le jeu.
