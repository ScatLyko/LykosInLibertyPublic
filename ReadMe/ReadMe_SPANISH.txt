 Requisitos del sistema 
_______________________

Sistemas operativos soportados:

Grand Theft Auto III emplea Microsoft DirectX 8.1.
Los sistemas operativos soportados son:

	Windows 98
	Windows 98 Segunda Edición 
	Windows Millennium
	Windows 2000 Profesional (Estación de trabajo)
	Windows XP (Usuario y Profesional)

Los siguientes sistemas operativos NO son soportados:

	Windows 95
	Windows NT (cualquier versión)
	Mac OS
	Linux
	BEOS

Requisitos mínimos de sistema 
	
	Procesador Intel Pentium III o AMD Athlon a 450MHz 
	96MB de RAM
	Lector de CD / DVD de 4x 
	700MB de espacio libre en el disco duro 
	Tarjeta de vídeo de 16MB con controladores compatibles con 
	DirectX 8.1 
	Tarjeta de sonido compatible con DirectX 8.1 
	Teclado
	Ratón

Requisitos de Hardware recomendados
	Procesador Intel Pentium III o AMD Athlon a 700MHz (o +)
	128MB (o +) de RAM
	Lector de CD / DVD 8x 
	700 MB de espacio libre en el disco duro 
	Tarjeta de vídeo de 32MB (o +) compatible con DirectX 8.1 
	Tarjeta de sonido compatible con DirectX 8.1 y con sonido 
surround 
	Mando de juego (USB o puerto para Joystick)
	Teclado
	Ratón

 General
_________

DirectX:
Grand Theft Auto III necesita Microsoft DirectX 8.1 para ser ejecutado. 
Como consecuencia de esto, recomendamos que los controladores de vídeo 
y de sonido instalados sean compatibles con DirectX 8.1. Incluso se 
recomienda el uso de una verdadera tarjeta de hardware DirectX 8.0 / 
DirectX 8.1.

Windows XP:
Recomendamos los controladores para Windows XP distribuidos por el 
fabricante (p. ej.) controladores que muestren al usuario los controles 
para cambiar las configuraciones de una parte de hardware en cuestión), 
en lugar de los controladores instalados por defecto por Microsoft como 
parte del proceso de configuración de la máquina.

Memoria:
Grand Theft Auto III requiere al menos 96MB de memoria para funcionar. 
Para  un rendimiento óptimo se recomiendan al menos 128MB 
(preferentemente 256MB).

Aplicaciones en funcionamiento:
Grand Theft Auto III ha sido diseñado para sacar el máximo partido de 
la máquina en la que esté funcionando, por lo tanto te recomendamos que 
cierres todas las aplicaciones antes de ejecutar Grand Theft Auto III.

Espacio libre en el disco duro:
Grand Theft Auto III requiere al menos 200MB de espacio libre en el 
disco duro para usar como espacio de intercambio mientras se está 
ejecutando.

Memoria de vídeo:
Grand Theft Auto III necesita una tarjeta de vídeo con 16MB o más de 
memoria de vídeo. Grand Theft Auto III no se ejecutará si es puesto en 
marcha en una máquina con menos de 16MB de memoria de vídeo.

Procesadores AMD K6/2 y K6/III:
Estos dos procesadores AMD ejecutan Grand Theft Auto III a una 
velocidad demasiado baja como para ser aceptable.

 Instalación
_____________

Introduce el disco uno de Grand Theft Auto III en la unidad de CD / 
DVD. 
Si tienes activada la opción de reproducción automática entonces el 
programa de configuración se pondrá en marcha de modo automático. 
Si la opción de reproducción automática no está activada, entonces 
utiliza el Explorador para navegar por el disco uno de Grand Theft Auto 
III y ejecutar manualmente el programa setup.exe

Consumo de memoria
Grand Theft Auto III requiere aproximadamente 700MB de espacio en el 
disco duro.

Desinstalación 
Cuando se desinstala Grand Theft Auto III, no borramos los directorios 
"mp3", "skins" y "SaveGames". Depende del usuario el eliminarlas 
manualmente.

 Configuración
_______________

Proveedor de Sonido:
El API de sonido elegido dentro de las opciones de Grand Theft Auto III 
puede afectar al rendimiento del juego. Prueba con proveedores de 
sonido alternativos. Prueba con Software, MSS Fast, RSX, Hardware 
Direct Sound, Software Direct Sound.

Modelado acústico dinámico

Desconecta el modelado acústico dinámico en las Opciones de sonido para 
obtener una pequeña ganancia en el rendimiento.

Rastros
Desconecta el efecto de Trails (rastros) en las opciones de pantalla de 
Grand Theft Auto III para ayudar a aumentar la velocidad.

Resolución de pantalla
Selecciona resoluciones de pantalla más bajas en la configuración de 
pantalla de Grand Theft Auto III para permitir una respuesta más rápida 
en las máquinas de menores prestaciones. En estas circunstancias 
también ayudará el uso de color de 16 bits, en vez del de 32.

 Solución de problemas
______________________

Técnicamente este problema se soluciona utilizando una versión más actual del
d3d8.dll que viene con el CD de Windows XP. (La versión que vienen con el CD de
Windows XP que está dando problemas es la 5.1.26000.0 - las versiones que se han
probado sin errores incluyen la 5.1.2600.15 y la 5.1.2600.29)

Actualmente, la única forma conocida para actualizar este archivo dll es instalar
el parche de  Windows XP: "El ordenador no puede pasar a inactividad o hibernación
si se está ejecutando un salvapantallas basado en Direct3D (Q306676)" puedes
bajártelo de la siguiente página web:

http://www.microsoft.com/downloads/release.asp?ReleaseID=37957&area=search&ordinal=4

Puede que en un futuro esta actualización sea parte de un Paquete de Servicios
Oficial de Windows XP, una actualización de compatibilidad Windows XP, o posiblemente una actualización de DirectX 8.1.

Tarjetas de vídeo Power VR Kyro 2 
Hemos sido incapaces de soportar completamente esta tarjeta debido a la 
naturaleza del renderizado de la misma, y como consecuencia de ello, 
algunos efectos de textura no se muestran correctamente, aunque estos 
son menores.
Recomendamos que esta tarjeta de vídeo se utilice en modos de pantalla 
de 32 bits, ya que en 16 bits descubrimos un raro problema con la 
profundidad del búfer, el cual está resuelto en 32 bits. También 
recomendaríamos hacer los siguientes cambios en la configuración:
=> Ve a la opción avanzada de propiedades de pantalla 
	Selecciona la ficha Optimización 3D, y crea un nuevo perfil para 
	gta3.exe.
	Entonces dentro de este perfil haz lo siguiente:
		DESABILITA Forzar búfer W
		HABILITA Habilitar búfer de profundidad/patrón externo
		HABILITA Direct 3d / Habilitar búfer de profundidad 
		HABILITA patrón búfer de profundidad 
		HABILITA cargar patrón búfer de profundidad 

Tarjetas de sonido Aureal:
Se nos han notificado muchos problemas de cuelgues y bloqueos con las 
tarjetas de sonido Aureal. Este fabricante ha dejado el negocio y no 
está poniendo en circulación nuevos controladores. En el pasado, hemos 
tenido muchos problemas a la hora de contemplar la compatibilidad con 
las tarjetas Aureal, y con los controladores que existen en la 
actualidad, estos problemas no pueden ser solucionados - aunque sus 
usuarios pueden probar con proveedores de sonido que no sean Aureal, lo 
que podría ser más efectivo que el proveedor Aureal nativo (p. ej. 
Software, MSS Fast, RSX, Hardware Direct Sound, Software Direct Sound).

Chips de sonido integrados en la tarjetas base:
Hemos descubierto que algunos chipsets de sonido integrados en la 
tarjetas base no informan de tener un búfer de hardware de sonido, y se 
bloquean con Grand Theft Auto III. Descubrimos que al ejecutar "DXDIAG" 
de Microsoft y realizar las pruebas de sonido aparece un mensaje de 
error diciendo que no se soporta un búfer por hardware. Selecciona un 
búfer por software para que este chipset de sonido funcione con Grand 
Theft Auto III.

Defragmentación del disco duro 
Si experimentas interrupciones cortas y periódicas mientras conduces, 
Grand Theft Auto III puede estar teniendo problemas con la recuperación 
de información de tu disco duro a una tasa lo suficientemente rápida.  
Se recomienda que ejecutes la utilidad de defragmentación del sistema 
de modo regular para permitir una velocidad óptima en el rendimiento 
del juego.
