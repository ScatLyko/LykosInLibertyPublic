 ALLGEMEINE INFORMATIONEN
_________________________


DirectX:

GTA 3 benötigt Microsoft DirectX 8.1. Folglich sollten auch die Grafik- 
und Soundtreiber auf Ihrem Computer DirectX 8.1 kompatibel sein. 
Noch bessere Ergebnisse erzielen Sie mit einer echten Hardware DirectX 
8.0 / DirectX 8.1 Karte.


Windows XP:

Für Windows XP empfehlen wir Treiber, die von den Kartenherstellern 
vertrieben werden, statt der von Microsoft installierten Standardtreiber. 
Erstere Treiber sind oft mit Steuerungselementen ausgestattet, die es dem 
User erlauben, die Einstellungen der jeweiligen Hardware-Komponente 
zu verändern.


Speicher:

GTA 3 benötigt mindestens 96 MB Arbeitsspeicher. Für eine optimale 
Performance werden mindestens 128 MB (besser noch 256 MB) empfohlen.


Andere Programme:

GTA 3 wurde darauf ausgelegt, das jeweilige System, auf dem es läuft, 
optimal auszunutzen. Wir empfehlen daher, alle anderen Programme zu 
schließen, bevor Sie GTA 3 starten.


Festplattenspeicher:

GTA 3 benötigt während des Spiels mindestens 200 MB freien 
Festplattenspeicher zum Zwischenspeichern von Daten.


Grafikspeicher:

GTA 3 benötigt eine Grafikkarte mit mindestens 16 MB Speicher. Auf 
Systemen mit weniger als 16 MB Grafikspeicher kann GTA 3 nicht gespielt 
werden.


AMD K6/2 und K6/III Prozessoren:

Auf diesen beiden AMD Prozessoren läuft GTA 3 erheblich zu langsam. 
Die Performance des Spiels auf diesen Prozessoren ist inakzeptabel.

 INSTALLATION
_____________

Legen Sie GTA 3 Disk Eins in Ihr CD / DVD Laufwerk. 
Falls Sie Autostart aktiviert haben, startet der Setup-Vorgang automatisch. 
Ist Autostart nicht aktiviert, steuern Sie mit dem Windows Explorer die 
GTA 3 Disk Eins an und starten Sie die Datei setup.exe manuell.

Festplattenspeicher
GTA 3 benötigt etwa 700 MB Festplattenspeicher.

Deinstallieren
Wird GTA 3 deinstalliert, so werden die Verzeichnisse "mp3", 
"skins" und "SaveGames" nicht gelöscht. Bitte entfernen Sie diese Ordner 
manuell, falls Sie dies wünschen.

 KONFIGURATION
______________

Sound-Schnittstelle:
The Sound-Schnittstelle (API), die in den GTA 3 Optionen selektiert wird, 
kann die Performance des Spiels beeinträchtigen. Versuchen Sie alternative
Sound-Schnittstellen, um bessere Resultate zu erhalten: Software, MSS Fast, 
RSX, Direct Sound Hardware oder Direct Sound Software.

Dynamische Akustik:
Dekativieren Sie "Dynamische Akustik" in den Sound-Optionen, um die 
Performance leicht zu verbessern.

Bewegungsunschärfe
Deaktivieren Sie die Bewegungsunschärfe-Effekte (Unschärfe-FX), um die 
Geschwindigkeit der Performance zu erhöhen.

Bildschirmauflösung
Die Auswahl einer geringeren Bildschirmauflösung erlaubt ein schnelleres
Gameplay auf langsameren Computern. In diesem Zusammenhang ist es auch 
hilfreich, 16-Bit Farben statt 32-Bit Farben zu verwenden.

 BEKANNTE PROBLEME
__________________

Windows XP + Grafikkarten mit nVIDIA-Grafikprozessoren:

Hier treten mitunter Grafik-Probleme sowohl im Spielmenü als auch im 
Spiel selbst auf. Es handelt sich hier um ein Problem von Windows XP.
Technisch wird dieses Problem durch die Verwendung einer neueren 
Version der Datei d3d8.dll gelöst, als der Version, die werksmäßig auf 
der Windows XP CD enthalten ist. (Die Nummer der Version auf der 
Windows XP CD, die Probleme verursacht, lautet 5.1.26000.0 - Versionen 
mit den Nummern 5.1.2600.15 und 5.1.2600.29 verursachten bei unseren 
Tests keine Probleme. 
Momentan kann dieses Problem nur behoben werden, indem der XP Patch 
mit der Kennnummer Q306676 und dem Namen 
"Windows XP Patch: Direct3D-based Screen Saver Hibernate/Standby Error"
installiert wird. Sie finden diesen Patch unter: 

http://www.microsoft.com/downloads/release.asp?ReleaseID=37943&area=search&ordinal=5     

Möglicherweise wird dieses Update in Kürze als Bestandteil eines offiziellen 
Windows XP Service Packs, eines Windows XP Compatibility Updates oder eines 
DirectX 8.1 Updates verfügbar sein.


Power VR Kyro 2 Grafikkarten:

Aufgrund der Art und Weise, wie diese Karte Daten rendert, konnten wir 
sie nicht voll unterstützen, wodurch einige Textur-Effekte nicht korrekt 
dargestellt werden. Diese Ausfälle sind jedoch nicht dramatisch. Wir 
empfehlen, diese Grafikkarte im 32-Bit Bildschirmmodus zu betreiben, 
da im 16-Bit Modus ein seltener Puffer-Fehler aufgetreten ist, der im 
32-Bit Modus nicht auftritt. Wir empfehlen außerdem, folgende 
Einstellungsänderungen vorzunehmen:
	
	- Gehen Sie in die Box Eigenschaften von Anzeige//Erweitert
	- Wählen Sie die Direct 3D Seite aus und legen Sie ein neues 
	  Profil für gta3.exe an.
	- Innerhalb dieses Profils:
		DEAKTIVIEREN Sie W buffer
		AKTIVIEREN Sie external depth / stencil buffer format
		AKTIVIEREN Sie Direct 3d / stencil buffer format
		AKTIVIEREN Sie depth / stencil buffer format
		AKTIVIEREN Sie depth / stencil buffer loading


Aureal Soundkarten:

Bei Aureal Soundkarten sind etliche Crashs aufgetreten. Dieser 
Hersteller hat den Handel eingestellt und bringt keine neuen Treiber 
mehr heraus. Wir hatten schon in der Vergangenheit viele Probleme bei 
der Unterstützung von Aureal Soundkarten, die sich mit den 
gegenwärtigen Treibern nicht beheben lassen, obgleich sich hier mit 
Nicht-Aureal Sound Providern u.U. einige Verbesserungen erzielen 
lassen. Solche Provider sind u.a. Software, MSS Fast, RSX, Direct 
Sound Hardware oder Direct Sound Software.


Mainboard-basierte Sound-Chips:

Wir haben herausgefunden, dass einige Mainboard-basierte Sound-
Chipsets nicht melden, dass sie einen Hardware-Soundpuffer haben, 
und die folglich mit GTA 3 crashen. Wenn die Benutzer Microsofts 
"DXDIAG" ausführen die Soundtests durchführen erhalten sie die 
Fehlermeldung, dass ein Hardware-Puffer nicht unterstützt wird und die 
Rückfrage, ob ein Software-Puffer verwendet werden soll. Wählt man 
einen Software-Puffer aus, so funktioniert das Sound-Chipset mit GTA 3.


Festplatten-Defragmentierung:

Sollten während Auto- oder sonstigen Fahrten kurze, wiederkehrende 
Verzögerungen auftreten, wäre es möglich, dass GTA 3 Probleme hat, 
benötigte Daten schnell genug von Ihrer Festplatte auszulesen. In 
diesem Fall wird empfohlen, die Festplatte regelmäßig zu defragmentieren 
(unter Programme/Zubehör/Systemzubehör/Defragmentierung), um die 
optimale Game-Performance sicherzustellen.
